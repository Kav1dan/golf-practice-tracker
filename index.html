資料與使用說明

  • 本程式不需要帳號，資料存在這台裝置的瀏覽器中。
  • 若在 iPhone 使用，建議固定用同一個 Safari 瀏覽器開啟 GitHub Pages 網址。
  • GitHub Pages 是網頁託管服務，不會自動同步不同裝置的資料。
  • 「合格球」請依照自己的球場目標設定；距離與方向都要考慮，不只看最遠的一球。
